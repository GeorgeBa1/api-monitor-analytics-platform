# A.P.I. Sentinel — Quick Start

**Version 3.0.0**

1. Start A.P.I. Sentinel.
2. On a new installation, complete **First Run Setup** and create the first ADMIN.
3. Log in.
4. Open **APIs** and add the first endpoint.
5. Configure **Settings** only when SMTP, Teams or external API authentication is required.
6. Click **Run Monitoring**.
7. Review **Dashboard**, **Endpoints**, **Analytics**, **Alerts** and **Reports**.
8. Use **Dashboard Manual** from the main navigation for guided operation.

> For production deployments, configure HTTPS, the production application secret and the production database according to the installation and hardening documentation.
